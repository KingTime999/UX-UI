# Mixi Chicken Store - Bootstrap Website

A responsive e-commerce website for Mixi Chicken Store, built with Bootstrap 5 for educational purposes.

## 📋 Description

This is a single-page website showcasing a fictional dried chicken product store inspired by Vietnamese streamer Độ Mixi. The website demonstrates the use of Bootstrap components and responsive design principles.

## ✨ Features

- **Responsive Design**: Mobile-first design that works on all devices
- **Bootstrap Grid System**: Utilizes Bootstrap's 12-column grid layout
- **10+ Bootstrap Components**:
  - Navbar with collapse menu
  - Hero section with CTA button
  - Carousel/Slider with 3 slides
  - Product cards with badges
  - Contact form with validation
  - Footer
  - Buttons and badges
  - Typography (lead text)

- **Interactive Music Player**: Background music toggle button with play/pause functionality
- **Smooth Navigation**: Anchor links to different sections
- **Professional Layout**: Clean and modern design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.2
- JavaScript (ES6)
- Audio API

## 🚀 How to Use

1. **Clone or download** this repository
2. **Open** `index.html` in your web browser
3. **Click** the music button (top-left corner) to play/pause background music
4. **Navigate** through sections using the navbar links

## 📦 Installation

No installation required! Simply open the HTML file in a modern web browser.

```bash
# Clone the repository
git clone https://github.com/KingTime999/UX-UI.git

# Navigate to Lab3 folder
cd UX-UI/Lab3

# Open in browser
start index.html  # Windows
open index.html   # macOS
```
